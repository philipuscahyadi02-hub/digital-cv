# Philipus Cahyadi — Digital CV

A single-page, dark-mode-first portfolio site built with Next.js (App Router) and Tailwind CSS.

## Structure

- `data/resume.ts` — all site content (summary, stats, experience, builds, skills, education, projects). Edit this file to update the site.
- `components/` — Nav, Hero, Experience, Builds, Skills, Education, Projects, Contact, plus `Reveal` (scroll-in animation), `ScrollFX` (section rail and scroll-linked effects) and `Spotlight` (cursor-follow glow).
- `components/previews/` — the small animated previews on the Builds cards (Tama, Onikiri, SNITCH, WangKu).
- `public/Philipus-Cahyadi-Resume.pdf` — the downloadable resume, generated by `npm run cv`.
- `tools/make-cv.js` — builds the resume as Word; `tools/docx-to-pdf.ps1` turns it into the PDF.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Push this folder to a GitHub repo.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo.
3. Framework preset auto-detects as Next.js — no config needed. Click Deploy.

Or via CLI:

```bash
npm i -g vercel
vercel
```

## Updating content

Edit `data/resume.ts` for the site.

For the downloadable resume, edit the content in `tools/make-cv.js` (it mirrors `data/resume.ts`, worded for print) and run:

```bash
npm run cv
```

This writes `tools/out/Philipus-Cahyadi-Resume.docx` (ignored by git) and regenerates `public/Philipus-Cahyadi-Resume.pdf`. The PDF step needs Microsoft Word on Windows; it warns if the resume runs past 2 pages.
